# README - Manual de Ejecución del Código de Limpieza de Datos
### Este README contiene los pasos para correr el código de limpieza de datos utilizado para el conjunto de datos bike_buyers.csv. Este proceso realiza una limpieza al manejar valores faltantes, corregir datos erróneos, y estandarizar y normalizar valores.

## Requisitos previos
Antes de comenzar, asegúrate de tener instalados los siguientes paquetes de Python:

- pandas - Para la manipulación y análisis de datos
- matplotlib y seaborn - Para la visualización de gráficos y distribución de datos

## Pasos para Ejecutar el Código
Clonar o descargar el repositorio en tu máquina:

git clone <https://github.com/A01747156/Herramientas_computacionales.git>

cd <Herramientas_computacionales>


Asegúrate de que el archivo bike_buyers.csv esté en la carpeta

## Ejecutar el script de limpieza de datos

- Tratamiento de valores faltantes.
- Conversión de tipos de datos incorrectos.
- Eliminación de duplicados.
- Detección y tratamiento de valores atípicos.
- Estandarización de valores categóricos.

Verificar los resultados: Una vez completado el proceso, revisa el conjunto de datos limpio y listo para el análisis.
